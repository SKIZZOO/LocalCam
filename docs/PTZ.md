# ONVIF PTZ

PTZ is optional and depends on the camera firmware exposing compatible ONVIF PTZ services.

Per camera, configure:

- ONVIF host/IP
- ONVIF port
- ONVIF username/password when different from RTSP credentials

The dashboard exposes directional controls, Home, and short continuous moves. Use **Test PTZ** from Settings before relying on the controls.

If ONVIF/PTZ is unavailable, RTSP live view and recording continue to work normally.
